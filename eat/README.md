# 今天吃什么？- 随机抽取应用

一个有趣的随机抽取应用，帮助您决定今天吃什么！界面设计成复古电视机的样子，包含拉伸绳子的交互功能。

## 功能特点

### 🎯 核心功能

- **随机抽取**: 从预设的食物组合中随机选择
- **拉伸绳子**: 通过拉动电视上方的绳子来开始抽取，拉得越远抽取时间越长
- **卡片动画**: 抽取过程中显示卡片上下翻折滚动的动画效果
- **组合管理**: 支持多个食物组合，可以自由切换

### 📱 界面特色

- **盒子外观**: 使用自定义盒子图片作为界面背景
- **响应式设计**: 支持桌面端和移动端
- **流畅动画**: 卡片翻转、绳子拉伸等丰富的动画效果

### 🔧 管理功能

- **组合管理**: 新增、编辑、删除、复制食物组合
- **选项管理**: 为每个组合添加、编辑、删除选项
- **历史记录**: 查看抽取历史，包含时间、组合、结果等信息
- **数据管理**: 导入、导出、重置数据

## 使用方法

### 1. 启动应用

直接在浏览器中打开 `index.html` 文件即可使用。

### 2. 开始抽取

- **点击按钮**: 点击"开始抽取"按钮
- **拉伸绳子**: 用鼠标或手指拉动盒子上方的金色绳子
- **键盘快捷键**: 按空格键开始抽取

### 3. 管理选项

点击"管理选项"按钮打开管理页面，可以：

- 创建新的食物组合
- 编辑现有组合和选项
- 复制组合
- 查看抽取历史
- 导入导出数据

### 4. 切换组合

点击当前组合名称旁边的"切换"按钮，选择不同的食物组合。

## 预置数据

应用包含以下预置组合：

- **默认组合**: 火锅、烤肉、寿司、披萨等常见美食
- **中餐精选**: 宫保鸡丁、麻婆豆腐、糖醋里脊等经典中餐
- **西餐精选**: 牛排、意面、三明治等西式美食
- **小吃零食**: 薯条、鸡翅、爆米花等休闲食品

## 注意事项

1. **数据安全**: 所有数据保存在浏览器本地存储中，清除浏览器数据会导致数据丢失
2. **文件访问**: 需要通过HTTP服务器访问才能正常加载JSON文件
3. **移动端**: 建议在移动端使用触摸操作来拉伸绳子

## 开发说明

### 本地开发服务器

可以使用以下方式启动本地服务器：

```bash
# 使用Python
python -m http.server 8000

# 使用Node.js
npx http-server

# 使用PHP
php -S localhost:8000
```

然后访问 `http://localhost:8000/eat/` 即可使用应用。

### 代码结构

- **模块化设计**: 功能分离，便于维护
- **事件驱动**: 使用事件监听器处理用户交互
- **数据驱动**: 基于JSON数据结构的动态界面

# 抽奖功能说明

## 功能概述

抽奖系统现在支持两种触发方式：

1. **点击抽奖**：立即开始抽奖，使用默认时间（15 秒）
2. **长按抽奖**：长按按钮可以延长抽奖时间（最多延长 5 秒）

## 随机性增强

### 复合随机种子

系统使用多个元素生成随机种子，确保每次抽奖结果的随机性：

- **当前时间**：精确到毫秒的时间戳
- **长按时间**：用户长按按钮的持续时间
- **点击位置**：鼠标/触摸的坐标位置
- **按钮按下时间**：按钮被按下的时间点
- **屏幕尺寸**：当前屏幕的宽度和高度
- **用户代理**：浏览器信息
- **时间组合**：鼠标位置和时间的组合

### 随机化效果

- **初始卡片**：随机选择开始显示的卡片
- **转动速度**：基于随机种子计算翻页动画速度（0.8-1.2 倍变化）
- **停顿时间**：基于随机种子计算卡片间的停顿时间（0.85-1.15 倍变化）
- **最终结果**：使用随机种子确定最终抽奖结果

## 操作方式

### 点击抽奖

- 直接点击"开始抽取"按钮
- 立即开始 15 秒的抽奖动画
- 使用当前时间作为随机种子

### 长按抽奖

- 按住"开始抽取"按钮
- 显示进度条，提示"准备中..."
- 长按超过 0.5 秒后开始抽奖
- 继续长按可以延长抽奖时间（最多延长 5 秒）
- 进度条显示延长时间
- 松开按钮结束长按

## 技术实现

### 事件处理

- 支持鼠标和触摸事件
- 防止移动端长按菜单
- 处理鼠标离开和触摸取消事件

### 动画控制

- 翻书式卡片切换动画
- 随机化的动画速度和停顿时间
- 基于时间的动画结束控制

### 错误处理

- 防止无效的动画持续时间
- 状态检查和重置机制
- 详细的调试日志

## 配置参数

```javascript
animationConfig: {
  flipDuration: 800,        // 翻页动画持续时间（毫秒）
  pauseDuration: 500,       // 每个卡片展示后的停顿时间（毫秒）
  totalDuration: 15000,     // 抽奖总持续时间（毫秒）- 默认 15 秒
  longPressDelay: 500,      // 长按延迟时间（毫秒）
  maxLongPressBonus: 5000,  // 最大长按延长时间（毫秒）- 5 秒
}
```

## 使用建议

1. **快速抽奖**：直接点击按钮，适合快速决定
2. **仪式感抽奖**：长按按钮，增加抽奖的仪式感和期待感
3. **延长抽奖**：长按更长时间，让抽奖过程更加刺激
4. **随机性**：每次点击位置和时间的不同都会影响最终结果

## 调试信息

系统会在控制台输出详细的调试信息，包括：

- 复合随机种子的生成过程
- 动画参数的计算结果
- 长按状态的变化
- 动画执行的进度

这些信息有助于理解系统的随机化机制和调试问题。

Vim 常用命令速查

Vim 中文手册（所有命令与参考）

常用模式命令分区
普通模式（Normal Mode）
命令 说明
h 光标左移
j 光标下移
k 光标上移
l 光标右移
w 跳到下一个单词开头（小写包含标点）
e 跳到当前单词结尾（小写包含标点）
b 以单词为单位往前跳（小写包含标点）
W 跳到下一个单词开头（大写不含标点）
E 跳到当前单词结尾（大写不含标点）
B 以单词为单位往前跳（大写不含标点）
^ 跳到当前行首
$ 跳到当前行尾
gg 跳到文档第一行
[N]G 跳到第 N 行，省略 N 跳到最后一行
dd 删除当前行
普通模式（Normal Mode）
命令 说明
dw 删除一个单词
x 删除光标后的字符
X 删除光标前的字符
D 删除至行尾
[N]yy 或 Y 复制当前行或 N 行
yw 复制一个单词
p 在光标后粘贴
P 在光标前粘贴
u 撤销上一步操作
Ctrl + r 恢复撤销
. 重复上一次命令
/pattern 向下搜索 pattern
?pattern 向上搜索 pattern
n 下一个匹配项
N 上一个匹配项
o 在当前行下方新开一行并进入插入模式
底线命令模式（Command Mode）
命令 说明
:w 保存文件
:wq 或 :x 保存并关闭文件
:q 关闭文件（未保存会提示）
:q! 强制关闭文件，不保存修改
:set nu 显示行号
:set nonu 取消显示行号
:set paste 粘贴模式（避免自动缩进）
:%s/old/new/g 全文件替换 old 为 new
:split 水平分割窗口
:vsplit 垂直分割窗口
:close 关闭当前窗口
Ctrl + w h/j/k/l/w 窗口间切换
输入模式（Insert Mode）
命令 说明
i 在光标前插入
I 在行首插入
a 在光标后插入
A 在行尾插入
o 在当前行下方新开一行
O 在当前行上方新开一行
Esc 退出插入模式
视觉模式（Visual Mode）
命令 说明
v 字符选择模式
V 行选择模式
Ctrl + v 块选择模式
d 删除选中内容
y 复制选中内容
屏幕滚动与光标移动
快捷键 作用说明
屏幕滚动相关
Ctrl + e 向下滚动一行（屏幕内容下移一行，光标不动）
Ctrl + y 向上滚动一行（屏幕内容上移一行，光标不动）
Ctrl + d 向下滚动半屏（down half page）
Ctrl + u 向上滚动半屏（up half page）
Ctrl + f 向下滚动一整屏（forward page）
Ctrl + b 向上滚动一整屏（backward page）
快捷键 作用说明
光标移动相关（常用）
gg 跳到文件第一行
G 跳到文件最后一行
H 跳到屏幕顶部第一行
M 跳到屏幕中间那一行
L 跳到屏幕底部那一行
zz 当前行滚动到屏幕中间
zt 当前行滚动到屏幕顶部
zb 当前行滚动到屏幕底部
